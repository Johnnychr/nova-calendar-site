NOVA Calendar

NOVA Calendar is a personal Google Calendar integration for the NOVA home assistant.

Purpose

The integration allows an authorized user to request information from their own Google Calendar through NOVA.

Google Calendar access

NOVA Calendar requests read-only Google Calendar access. It does not create, modify, or delete Google Calendar events.

Privacy

For information about how Google Calendar data is handled, see the NOVA Calendar Privacy Policy.
