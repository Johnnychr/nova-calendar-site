NOVA Calendar Privacy Policy

Effective date: October 4, 2026

Overview

NOVA Calendar is a personal integration used with the NOVA home assistant. Its purpose is to let an authorized user ask NOVA for information from their own Google Calendar.

Google data accessed

NOVA Calendar requests read-only access to Google Calendar. Calendar information may include event titles, dates, times, and other event information required to answer the authorized user's calendar request.

How the data is used

Google Calendar data is used only to provide calendar functionality requested by the authorized user. NOVA Calendar does not use Google Calendar data for advertising, marketing, profiling, or sale.

Data sharing

Google Calendar data is not sold or shared with advertisers. The integration is intended for personal use and does not provide calendar data to the public.

Access and control

Access is authorized through Google's OAuth consent process and can be revoked by the Google account holder through their Google Account permissions.

Security

The public website contains no calendar data and provides no access to the NOVA home assistant or its private systems.

Google API Services User Data Policy

NOVA Calendar's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
